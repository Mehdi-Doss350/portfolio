# Mehdi Doss | Portfolio

This is my personal portfolio, built to showcase my work as a Computer Science Engineering student at ENSI, specializing in Artificial Intelligence and Computer Vision, with hands-on experience as a full-stack software engineer. It highlights projects spanning intelligent assistants, machine learning models, and complete, production-oriented applications — from industrial data analysis to autonomous field inspection — alongside my professional experience, technical skills, and a contact form.

## Design

I chose a dark, tech-inspired visual style with subtle 3D elements because it reflects the domain I work in — AI, computer vision, and full-stack engineering — and the way I personally see and engage with technology. It felt like the most natural way to represent both my work and my passion for the field.

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js and React Three Fiber
- Motion

## Run Locally

Requirements: Node.js 20+ and npm 10+.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Production Build

```bash
npm run build
```

The generated files are placed in `dist/`.

## Deployment

Deploy the project root with Vercel or any Vite-compatible host.

- Build command: `npm run build`
- Output directory: `dist`
- Root directory: repository root
